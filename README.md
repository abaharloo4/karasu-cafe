# ☕ بی کافه شیراز (B Cafe Shiraz) — نسخه ۱.۰.۰ (Production v1.0.0)

سامانه جامع، بومی و بلادرنگ مدیریت کافه، سفارش آنلاین، اشتراک‌های قهوه روزانه، ناوگان اختصاصی پیک، باشگاه وفاداری، صندوق فروشگاهی (POS) و مانیتور زنده بار با استانداردهای مدرن PWA و طراحی لوکس ریال/تومان و تقویم تمام‌شمسی (Jalali).

---

## 🌟 مشخصات و قابلیت‌های کلیدی سامانه

### ۱. منوی آنلاین و استورفرانت (Storefront & Digital Menu)
* منوی دیجیتال واکنش‌گرا و سریع بدون نیاز به دانلود اپلیکیشن
* آیکون‌های وکتوری اختصاصی و متمایز برای دسته‌بندی‌ها (نوشیدنی گرم، نوشیدنی سرد و شیک، کیک و دسر، قهوه تخصصی و اقلام همراه)
* سبد خرید لحظه‌ای، کنترل تعداد، توضیحات و افزودنی‌های محصول (Add-ons)
* سیستم کوپن تخفیف، انتخاب نوع تحویل (حضوری یا پیک شیراز با محاسبه هزینه پهنه‌بندی)
* اتصال به درگاه پرداخت آنلاین شاپرک (زرین‌پال) و پرداخت مستقیم کارت‌به‌کارت با امکان بارگذاری فیش و بررسی توسط صندوق

### ۲. سیستم اشتراک هوشمند قهوه (Coffee Subscriptions)
* تعریف پلن‌های متنوع با تعداد فنجان، دوره اعتبار (مثلاً ۳۰ روزه) و محصولات مجاز اختصاصی
* خرید آنلاین اشتراک توسط مشتری یا تخصیص در صندوق توسط ادمین
* مصرف روزانه در بار با ۱ کلیک یا با بارکد/موبایل
* استعلام مانده سهمیه و تاریخ انقضا در پنل مشتری و بخش صندوقدار

### ۳. صندوق فروشگاهی و پوز حضوری (POS & Daily Usage)
* ثبت سفارش سریع با شماره موبایل یا به صورت مشتری عبوری
* اعمال خودکار تخفیف سهمیه روزانه اشتراک بدون ارور سبد خالی
* صدور آنی فاکتور حرارتی استاندارد ۸۰ میلی‌متری (فیش‌پرینتر) با قابلیت سفارشی‌سازی فونت، لوگو و متون پایین فیش
* ارسال بلادرنگ تمام سفارشات حضوری و آنلاین به مانیتور باریستا

### ۴. مانیتور زنده و ۴ مرحله‌ای بار و آشپزخانه (Live Kitchen & Bar Board)
* مانیتورینگ بلادرنگ سفارشات در ۴ وضعیت استاندارد:
  1. `pending` / `awaiting_payment_verification` (در انتظار تأیید یا بررسی فیش)
  2. `preparing` / `processing` (در حال آماده‌سازی در بار)
  3. `ready` / `shipping` (آماده تحویل یا در مسیر ارسال)
  4. `completed` (تحویل‌شده و بسته شده)
* پایش با پولینگ بهینه‌سازی‌شده JSON بدون بار اضافه روی سرور

### ۵. نمای ۳۶۰ درجه مشتری و پرسنل (Customer 360 & User Management)
* صفحه پروفایل جامع مشتری (`/admin/customers/{id}`): موجودی کیف پول، امتیازات باشگاه مشتریان، سهمیه اشتراک فعال، تاریخچه کامل سفارشات، آدرس‌های ذخیره‌شده و تاریخ تولد
* مدیریت کاربران و پرسنل (`/admin/users`): تعریف دسترسی‌های `admin`, `staff`, `cashier`

### ۶. باشگاه مشتریان و سطوح وفاداری (Loyalty Club & Gamification)
* سطوح وفاداری داینامیک (برنزی، نقره‌ای، طلایی، VIP)
* کش‌بک درصدی خودکار به کیف پول با انجام خرید
* گردونه شانس روزانه با انیمیشن روان و جوایز واقعی
* تبریک تولد خودکار با ارسال پیامک و شارژ هدیه با پترن‌های ملی‌پیامک

### ۷. سیستم نوتیفیکیشن و وب‌اپلیکیشن (PWA & Push Notifications)
* جایگزینی تمام آلرت‌های مرورگر با سیستم لوکس و اختصاصی توست بی کافه (`window.CafeToast`)
* پشتیبانی کامل از Web Push، سرویس‌ورکر و نصب مستقل روی اندروید، iOS و دسکتاپ
* ثبت تلمتری و آمار ۱۰۰٪ واقعی از بازدیدها (`page_view`) و نصب‌های وب‌اپ (`install`)

## 🛠️ تکنولوژی‌های به‌کار رفته

- **بک‌اند:** PHP 8.3+, Laravel 11 / 13 (Blade Monolith)
- **دیتابیس:** MySQL با ایندکس‌های بهینه‌سازی سرعت و کامپوزیت ایندکس
- **فرانت‌اند:** Tailwind CSS 3, Alpine.js, Vazirmatn Font
- **تقویم و تاریخ:** تقویم جلالی بومی (`morilog/jalali`) همراه کامپوننت اختصاصی `<x-persian-date-picker>`
- **پیامک:** درگاه ملی‌پیامک (Melli Payamak Pattern API) همراه شبیه‌ساز لوکال
- **پرداخت:** درگاه پرداخت زرین‌پال شاپرک + پرداخت کارت‌به‌کارت امن

## 🚀 راهنمای راه‌اندازی محلی (Quick Start)

### ۱. نیازمندی‌ها
- PHP 8.2 یا بالاتر با اکستنشن‌های `pdo_mysql`, `curl`, `mbstring`, `fileinfo`, `gd`
- سرور دیتابیس MySQL
- Node.js 18+ و NPM
- Composer 2+

### ۲. نصب پکیج‌ها و تنظیم محیط
```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
```

### ۳. تنظیمات دیتابیس در `.env`
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=karasu_cafe
DB_USERNAME=root
DB_PASSWORD=
```

### ۴. اجرای مایگریشن‌ها و سیدر
```bash
php artisan migrate
```

### ۵. کامپایل فرانت‌اند و اجرای سرور
```bash
npm run build
php artisan serve --port=8000
```

## 👥 نقش‌ها و دسترسی‌های پیش‌فرض

- **مدیر کل (Admin):** دسترسی به تمام گزارش‌های اکسل، تنظیمات پیامک، فاکتور، پرسنل، رانندگان و استقرار
- **پرسنل / باریستا (Staff):** دسترسی به مانیتور بار، ثبت سفارش، مصرف سهمیه و منو
- **راننده (Driver):** دسترسی به پنل پیک `/driver` و سفارشات تحویل شیراز
- **مشتری (Customer):** دسترسی به پنل سفارش آنلاین و باشگاه وفاداری `/customer/login`
